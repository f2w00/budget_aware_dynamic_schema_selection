14. GoLLIE — Guideline-based Information Extraction

Sainz, O., García-Ferrero, I., Agerri, R., Lacalle, O., Rigau, G., Agirre, E.: GoLLIE: Annotation Guidelines improve Zero-Shot Information-Extraction. ICLR (2024).

论文：GoLLIE — ICLR 2024

做了什么：

GoLLIE 研究的是 LLM 如何理解动态给定的 IE schema / annotation guidelines。作者通过微调让模型学会遵循详细的抽取规范，从而提高 zero-shot IE。

和你有什么关系：

你的 Schema 也是动态裁剪后交给 LLM 的，因此可以用它支持：

Schema definitions and guidelines strongly influence LLM-based information extraction.

但它不是效率/预算方法，所以属于背景文献，不是直接 baseline。

15. MetaRetriever — Universal IE 中的任务相关检索

Cong, X., Yu, B., Fang, M., et al.: Universal Information Extraction with Meta-Pretrained Self-Retrieval. Findings of ACL (2023), 4084–4100.

DOI: 10.18653/v1/2023.findings-acl.251

ACL Anthology 页面

做了什么：

MetaRetriever 认为不同 IE 任务需要不同知识，因此从预训练语言模型中检索 task-specific knowledge，再辅助统一 IE。

对你有用的地方：

它可以作为你“不同记录需要不同 schema / field”这个思想的旁证：

different extraction instances/tasks may require different task-specific information.

而你的方法进一步把这种思想落实到record-level field selection。

16. GLiNER — 轻量级可变 Schema NER

Zaratiana, U., Tomeh, N., Holat, P., Charnois, T.: GLiNER: Generalist Model for Named Entity Recognition using Bidirectional Transformer. NAACL-HLT (2024), 5364–5376.

DOI: 10.18653/v1/2024.naacl-long.300

ACL Anthology 页面

做了什么：

GLiNER 使用 bidirectional Transformer，不像普通 NER 模型那样固定 entity types，而是允许用户输入任意 label/type，然后进行实体抽取。

一个很重要的特点是：

schema/type 可以在 inference 时动态指定。

对你有用：

可以支持你论文里“schema 并不一定是静态固定 contract”的背景论述。

另外 GLiNER 本身也是轻量模型，非常适合说明不一定所有 schema-related decision 都需要调用大 LLM。

二、和你的“效率/预算”最相关18. Prompt Compression with Context-Aware Sentence Encoding

Liskavets, B., Ushakov, M., Roy, S., Klibanov, M., Etemad, A., Luke, S.K.: Prompt Compression with Context-Aware Sentence Encoding for Fast and Improved LLM Inference. AAAI (2025).

DOI: 10.1609/aaai.v39i23.34639

AAAI 论文页面

做了什么：

CPC 在 prompt compression 中计算句子级 relevance score，然后删除不重要的内容，从而减少输入 token。

和 LLMLingua 类似，但它更强调：

根据 query/context 判断哪些 prompt 内容值得保留。

与你的方法非常接近的地方：

它是：

relevance estimation → remove irrelevant content → reduce tokens

你的是：

field relevance estimation → remove irrelevant schema fields → reduce tokens

所以这篇其实很适合用来支撑你的**“schema pruning 本质上也是一种结构化 prompt compression”**的观点。

19. Inference-Aware Prompt Optimization

Mahmud, S., Nakamura, M., Wray, K.H., Zilberstein, S.: Inference-Aware Prompt Optimization for Aligning Black-Box Large Language Models. AAAI (2026), 32455–32464.

DOI: 10.1609/aaai.v40i38.40521

AAAI 2026 论文

做了什么：

IAPO 把 prompt quality 和 inference budget 联合考虑，在固定预算下优化 prompt / inference scale。

它和你的论文有一个很好的共同点：

不是单纯追求 extraction quality，而是把 inference budget 纳入决策。

你可以用它支撑“budget-aware LLM inference”这个研究方向。

20. Token-Budget-Aware Pool Routing

Chen, H., Liu, X., Jiang, J., He, B., Liu, X.: Token-Budget-Aware Pool Routing for Cost-Efficient LLM Inference. arXiv (2026).

这篇比较新，目前是预印本，所以如果你导师强调 DOI/正式发表，就暂时不要放主参考文献。

做了什么：

根据请求预测 token budget，再把短请求和长请求分配给不同的 LLM serving pool。

它和你最大的共同点：

在 LLM 调用之前估计 token cost，然后根据 budget 做决策。

只是它优化的是 serving infrastructure，你优化的是 schema composition。

所以这篇很适合你理解相关工作，但我暂时不建议作为 PDCAT 的核心参考文献。

三、Schema 动态化方向 21. DSE-RE

Springer 论文页面

而且这是一篇 2026 正式期刊文章，比较适合补进你的 Related Work。

四、数据库 Schema Pruning —— 这个其实非常值得你看 23. SRSPSQL: Schema Pruning for Text-to-SQL
