# Repository Access Note

Paper: *Budget-Aware Dynamic Schema Selection for Efficient LLM-Based Information Extraction Pipeline*

## Repository URL

https://github.com/f2w00/budget_aware_dynamic_schema_selection

## Access and setup

The repository README provides installation instructions, the test command,
and an overview of the main scripts. Consult the script arguments for required
local inputs and model directories.

The project README supplied with this source tree states that training data,
model files, raw experimental outputs, and paper materials are not distributed
with the repository. Check the published repository for its current contents;
do not assume that the URL provides every experimental artifact described
in the paper.

Include this note in the supplementary submission archive so readers can locate
the repository referenced in the paper.
