# 湖南博物馆外部参考质量对照实验记录

## 目的

用独立于被测模型的“证据参考”重评湖南 `without_url` 批次的 `full`、`budget-200`、
`budget-400`，替代“拿被测模型自己的 full 输出当参考”的循环口径，用于**方法之间的横向对比**。

## 背景与问题

- 原口径（见 `doc/湖南博物馆n100预算质量实验记录.md`）以 `kg-assist-pro` 的 full 输出作为
  held-out 参考。参考与候选同源，`full` 天然接近天花板，F1 被抬高，无法反映真实一致性。
- 湖南 `without_url` 的 `raw_data` 只有 5 个键（`尺寸`、`年代`、`类型`、`artifact_id`、
  `文物名称`）；held-out 350 条中 `类型` 恒为“书画类”，`年代` 共 22 种。
- 旧 `heldout_full_silver_reference.jsonl` 平均每记录 15.29 个非空字段，其中
  `region`/`site`/`culture`/`craft` 等 80% 以上非空值在原文中没有任何依据，属被测模型外推。

## 参考定义

- 脚本：`benchmarks/build_hunan_reference_v2.py`（**不调用 LLM**）。
- 产物：`data/hunan_museum_300000001_300000500_without_url/agent_reference_v2.jsonl`
  （350 条，`reference_model=agent-evidence-reference-v2`，`schema_version=simple2-v1`）。
- 生成规则（按 `gold_reference.prompt` 精神）：`name`←`文物名称`；`category`←`类型`；
  `dynasty`/`period`←`年代`；`desc`←原文摘要；`form_type`←名称关键词；其余字段无原文依据一律
  输出 `null`。本口径使用 `--no-manual`，不使用人工裁决表，完全可复现。
- 字段分布：平均非空 `5.477`（min `3` / max `9`）；逐字段——`name`/`category`/`desc` 各
  `350`、`period` `347`、`form_type` `273`、`dynasty` `210`、`related_person` `21`、
  `site` `11`、`region` `4`、`culture` `1`。

## 参考的边界

该参考独立于被测模型，可打破循环偏差；但仍是 model-assisted、非人工金标准，且规则保守
（模型正确提及、而名称未字面出现的 `related_person`/`site` 会被计为 FP），因此是**保守下界**，
只能用于方法间横向比较，不作绝对质量结论。

## 结果（配对 350 条）

| 方法 | Precision | Recall | 记录级 F1 | Micro-P | Micro-R | Micro-F1 | Exact | Coverage | 平均总 Token |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| full | 0.3887 | 0.9094 | 0.4901 | 0.3262 | 0.9103 | 0.4803 | 0.5593 | 1.0000 | 492.02 |
| budget-200 | 0.4360 | 0.6677 | 0.5144 | 0.4233 | 0.6750 | 0.5203 | 0.5239 | 0.6761 | 370.06 |
| budget-400 | 0.4000 | 0.9325 | 0.5196 | 0.3588 | 0.9343 | 0.5185 | 0.5629 | 1.0000 | 469.82 |

- `full` 平均 TP `4.99` / FP `10.30` / FN `0.49`；`budget-200` 平均 TP `3.70` / FP `5.04` /
  FN `1.78`；`budget-400` 平均 TP `5.12` / FP `9.15` / FN `0.36`。
- Token（input/output）：`full` `357.25`/`134.77`；`budget-200` `300.03`/`70.04`；
  `budget-400` `347.29`/`122.53`。

## 结论

- 三方法 F1 接近：记录级 F1 `0.490`--`0.520`，Micro-F1 `0.480`--`0.520`。
  `budget-400` 记录级 F1 略最高（`0.5196`），`budget-200` Micro-F1 略最高（`0.5203`），
  `full` 两项均最低。
- `full` 虽输出更多字段（平均高 FP `10.30`），precision 仅 `0.3887`；`budget-200` precision
  最高（`0.4360`）且 Token 最低（`370.06`，较 `full` 少约 `24.8%`），以较低 recall 换取。
- 对照：旧循环 full-silver 参考下 `full` F1 `0.6630`、`budget-200` `0.6658`；v1 证据参考下
  `full` precision `0.289`、F1 `0.392`。本独立参考下 `full` 的“优势”进一步消失。
- 因此本批次只能说明：在独立参考下预算方法不劣于 `full`，且 `budget-200` 以更少 Token 取得
  相当的一致性；不能据此声称绝对抽取质量或人工事实正确性。

## 口径影响

原 `doc/湖南博物馆n100预算质量实验记录.md` 中的质量表（`budget-200` Macro-F1 `0.6709` /
`budget-400` `0.8786` 等）是相对**同源循环参考**的一致性，不代表真实抽取质量；Token 结论不受影响。

```bash
uv run python benchmarks/build_hunan_reference_v2.py \
  --all-ids --no-manual \
  --output data/hunan_museum_300000001_300000500_without_url/agent_reference_v2.jsonl

uv run python evaluate_llm_experiments.py \
  --input \
    experiments/hunan_museum_300000001_300000500_without_url_full_silver/formal/full.jsonl \
    experiments/hunan_museum_300000001_300000500_without_url_budget_quality/formal/budget-200/budget-200.jsonl \
    experiments/hunan_museum_300000001_300000500_without_url_budget_quality/formal/budget-400/budget-400.jsonl \
  --gold data/hunan_museum_300000001_300000500_without_url/agent_reference_v2.jsonl \
  --require-methods \
    hunan-museum-300000001-300000500-without-url-full-stable \
    hunan-museum-without-url-n100-budget-200-stable \
    hunan-museum-without-url-n100-budget-400-stable \
  --output reports/hunan_museum_300000001_300000500_without_url_n100_m1/evidence_ref_v2_paired_metrics.json
```
