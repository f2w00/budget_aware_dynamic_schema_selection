## 1. 交接范围

本轮完成了三组离线模型策略实验，并保留此前的 FullSchema 训练样本量基线：

| 实验 | 内容 | run 数 | 产物根目录 |
| --- | --- | ---: | --- |
| 原始训练量消融 | 字符 TF-IDF，七个训练规模 | 35 | `models/training_size_ablation/`、`reports/training_size_ablation/` |
| M1 n=100 | 字符+词级 TF-IDF 拼接，阈值收缩 | 5 | `models/model_strategy_ablation/m1/`、`reports/model_strategy_ablation/m1/` |
| M2 全规模 | 字符/词级独立模型概率融合 | 35 | `models/model_strategy_ablation/m2/`、`reports/model_strategy_ablation/m2/` |
| M1 全规模 | M1 在七个训练规模上的效果变化 | 35 | `models/model_strategy_ablation/m1_by_size/`、`reports/model_strategy_ablation/m1_by_size/` |

所有实验只执行离线机器学习训练、预测、字段选择和评估，`llm_api_called` 均为 `false`，未调用
LLM API，也未覆盖正式模型和正式运行结果。

## 2. 固定实验协议

### 2.1 数据与隔离

| 文件 | 数量 | 用途 |
| --- | ---: | --- |
| `training_dataset.jsonl` | 6763 | FullSchema 银标训练样本 |
| `data/splits/train_ids.json` | 5410 | 唯一训练池 |
| `data/splits/validation_ids.json` | 677 | 阈值选择和验证 |
| `data/splits/test_ids.json` | 676 | 固定离线测试集 |
| `data/gold/gold_main_ids.json` | 500 | test 的固定子集，用于 Gold 覆盖评估 |

脚本启动时验证 train、validation、test 覆盖完整数据集且互不重叠；`gold_main` 不与 train 或
validation 重叠并完全属于 test。所有训练规模均从固定 5410 条 train pool 中抽取。

### 2.2 抽样协议

训练规模为：

```text
50 / 100 / 250 / 500 / 1000 / 2500 / 5410
```

每个规模使用 seed `42/43/44/45/46`。同一 seed 使用多标签缺口贪心顺序生成嵌套前缀，固定 seed
的微小随机扰动只用于打破平局，因此不是 uniform random sampling。相同 seed 下，小规模训练集是
大规模训练集的前缀。实际训练 ID 写入每个 run 的 `metadata.json`。

### 2.3 固定评估

- Schema：`simple2.json`，18 个字段。
- 字段权重和 required fields：`field_weights.json`。
- 字段成本：`schema_costs.json`。
- Presence：字段级 Precision、Recall、F1、Average Precision，及 Macro-F1、Micro-F1。
- Length：每字段 MAE、RMSE、MedAE、Spearman、正样本数和模型类型。
- Budget：预算 200/400，复用 `budget_selector.py` 的 0-1 knapsack。
- Gold 指标：Gold 非空记录数、Gold 非空覆盖率和整体覆盖率。
- 成本指标：平均 selected fields、estimated field cost、预算满足率。
- 稳定性指标：与同 seed 完整模型的逐记录字段集合 Jaccard、字段选择频率。
- 汇总：5 个 seed 的均值、样本标准差和 `1.96 * std / sqrt(5)` 的 95% 正态近似 CI。

Budget Jaccard 是逐 test 记录计算后再取均值，不是先对所有记录的字段集合做 union。

## 4. M1 n=100

### 4.1 方法

M1 使用字符级 TF-IDF `ngram_range=(2,5)` 与词级 TF-IDF `ngram_range=(1,2)` 拼接后的特征矩阵。
Presence 仍使用 `class_weight="balanced"`、`solver="liblinear"`、`max_iter=1000` 的
LogisticRegression；Length 使用 Ridge `alpha=10.0` 的 log1p 回归。validation 上选择 F1 最优阈值，
再将其向 0.5 收缩 25%，并限制到 `0.10--0.90`。

### 4.2 五个 seed 均值

| 方法 | Macro-F1 | Micro-F1 | Length MAE | Budget-200 覆盖 | Budget-400 覆盖 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始字符 TF-IDF | 0.5187 | 0.9126 | 4.8046 | 0.5166 | 0.9413 |
| M1 字符+词级 TF-IDF | 0.5088 | 0.9343 | 4.7615 | 0.5184 | 0.9415 |
| M1 - 原始 | -0.0098 | +0.0217 | -0.0431 | +0.0017 | +0.0003 |

M1 提升了 Micro-F1 和长度预测，但 Macro-F1 下降，说明收益主要来自高频字段，未解决长尾字段的
均衡识别问题。M1 不替代原始模型作为通用宏平均模型，但可作为小样本 Micro-F1 方案保留。

## 5. M2 全规模效果变化

### 5.1 方法

M2 分别训练字符级和词级 LogisticRegression，在 validation 上从字符概率权重
`0/0.25/0.5/0.75/1.0` 中选择 F1 最优值，其余权重分配给词级概率。阈值仍向 0.5 收缩 25%。
Length 使用字符+词级拼接表示，其他协议与 M1 相同。

### 5.2 n=100 五个 seed 对照

| 方法 | Macro-F1 | Micro-F1 | Length MAE | Budget-200 覆盖 | Budget-400 覆盖 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原始字符 TF-IDF | 0.5187 | 0.9126 | 4.8046 | 0.5166 | 0.9413 |
| M1 字符+词级 TF-IDF | 0.5088 | 0.9343 | 4.7615 | 0.5184 | 0.9415 |
| M2 概率融合 | 0.5083 | 0.9341 | 4.7615 | 0.5184 | 0.9405 |

在 n=100 时，M2 相比 M1 没有额外收益，Macro-F1 和 Micro-F1 略低，Budget-400 覆盖也略低。

### 5.3 七个规模的五 seed 均值

| 规模 | M2 Macro | M2 Micro | M2 MAE |
| ---: | ---: | ---: | ---: |
| 50 | 0.5003 | 0.9228 | 4.9307 |
| 100 | 0.5083 | 0.9341 | 4.7615 |
| 250 | 0.5534 | 0.9444 | 3.7199 |
| 500 | 0.5819 | 0.9485 | 3.4228 |
| 1000 | 0.6082 | 0.9519 | 3.2363 |
| 2500 | 0.6535 | 0.9568 | 2.9525 |
| 5410 | 0.6994 | 0.9607 | 2.9100 |

M2 的 Micro-F1 随训练规模从 0.9228 提升至 0.9607，Length MAE 从 4.9307 降至 2.9100；
Macro-F1 也从 0.5003 提升至 0.6994。该矩阵补齐了此前仅 n=100 的局限，但不改变 M2
在 n=100 未优于 M1 的结论。完整曲线位于 `tex/model_strategy_learning_curves.{png,pdf,svg}`，
并通过 `tex/model_strategy_learning_curves.alignment.json` 记录版面对齐检查。

## 6. M1 全规模效果变化

### 6.1 结果

| 规模 | 原始 Macro | M1 Macro | 原始 Micro | M1 Micro | 原始 MAE | M1 MAE |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 50 | 0.5156 | 0.4990 | 0.8909 | 0.9215 | 4.9682 | 4.9307 |
| 100 | 0.5187 | 0.5088 | 0.9126 | 0.9343 | 4.8046 | 4.7615 |
| 250 | 0.5522 | 0.5455 | 0.9296 | 0.9445 | 3.7907 | 3.7199 |
| 500 | 0.5940 | 0.5824 | 0.9362 | 0.9492 | 3.5017 | 3.4228 |
| 1000 | 0.6245 | 0.6075 | 0.9459 | 0.9517 | 3.3123 | 3.2363 |
| 2500 | 0.6916 | 0.6450 | 0.9590 | 0.9561 | 3.0084 | 2.9525 |
| 5410 | 0.7139 | 0.6962 | 0.9646 | 0.9612 | 2.9678 | 2.9100 |

### 6.2 结论

- M1 的 Micro-F1 在 `n=50--1000` 高于原始模型，最大增益是 n=50 的 `+0.0305`。
- n=2500 和 n=5410 时 M1 的 Micro-F1 分别低于原始模型 `0.0028` 和 `0.0034`。
- M1 的 Length MAE 在所有规模均改善，改善幅度为 `0.0375--0.0790`。
- M1 的 Macro-F1 在所有规模均低于原始模型，n=2500 的差距最大，为 `-0.0466`。
- 相对 M1 完整模型，Micro-F1 恢复率达到 90% 的最小规模为 50，达到 95% 为 1000，99% 未达到。
- Length MAE 恢复率达到 90% 和 95% 的最小规模均为 2500，达到 99% 为 5410。
- 该策略没有改善长尾字段的宏平均表现，不能作为原始模型的全面替代方案。

## 8. 解释边界与后续建议

- 训练标签来自已有 FullSchema 结果，是 silver/model-assisted reference，不是独立人工 Gold。
- `estimated_cost` 是字段选择阶段的离线估计，不是实际 API token 或货币成本。
- 置信区间是 5 个 seed 上的正态近似 CI，不是 bootstrap CI。
- 结果只说明离线字段存在性、长度预测和预算选择变化，不能直接等价为 LLM 端到端抽取质量、
  Value Score 或综合 Quality。
- M1 的主要收益集中在 Micro-F1 和长度 MAE，Macro-F1 仍受 condition、site、related_event、
  acq_type、craft_school 等长尾字段正样本不足限制。
- 下一步如继续做模型策略，优先验证针对长尾字段的共享表示、正则化或少样本稳健训练；不要修改
  已归档的 M1/M2 目录，使用新的方法名和独立产物根目录。
